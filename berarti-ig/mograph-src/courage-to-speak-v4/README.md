# The Courage to Speak, versi 4

Video storytelling "Raka diam 10 menit di rapat" dengan karakter vektor ber-rig (gaya Bold Editorial Stage).

- `Rig.tsx`: karakter vektor dengan sendi (bahu, siku, tangan, kaki, kepala, alis, mata, mulut), napas, kedip, follow-through.
- `Cast.tsx`: Raka (Arti), Sari dan Nadia (berhijab), Bimo (rambut keriting).
- `Ed.tsx`: judul editorial (label oranye, Archivo Black, satu kata kunci oranye), gerak mulut dari words.json, transisi iris.
- `Main.tsx`: 9 adegan sesuai storyboard, diatur ke waktu voice over.
- `audio-plan.json`: 45 cue SFX yang jatuh tepat di gerakan.

Voice over hasil kloning tidak disimpan di repo.
Render di proyek Remotion voynann-mograph: salin file ke `src/` dan `src/berarti/`, lalu `npm run render`.
