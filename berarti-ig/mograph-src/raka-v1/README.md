# Sumber motion grafis "Raka diam 10 menit di rapat" (v1)

Kode Remotion untuk video storytelling 24 November, dibuat dengan skill voynann-mograph dan style guide "Bold Editorial Stage".

- `berarti/Character.tsx`: tokoh Arti versi vektor (dipakai sebagai Raka) dan teman-teman rapat, dengan pose dan ekspresi.
- `berarti/UI.tsx`: judul editorial rata kiri, kartu bernomor, gelembung CONTOH, lantai hijau, Lingkaran Berani, subtitle.
- `berarti/Sets.tsx`: ruang rapat, kantor pagi, kamar malam, panggung, tangga penutup.
- `Main.tsx`: 14 adegan yang waktunya diambil dari kata di voice-over.
- `audio-plan.json`: rencana musik dan 23 efek suara.

Audio (voice-over kloning) sengaja tidak disimpan di repo. Untuk dipakai ulang: bootstrap proyek voynann-mograph baru, salin folder ini ke `src/`, salin font Archivo dan Poppins ke `public/fonts/brand/`.
